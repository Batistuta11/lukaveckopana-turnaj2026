  • Hlavni editovatelna data jsou v content/tournament.json.
  • Web ma hlavni sekce: hero, info karty, obhajce titulu, historie vitezu, informace pro tymy/navstevniky a propozice.
  • Existuje stranka /registrace s prihlasovacim formularem.
  • Existuje stranka /propozice s textem propozic, kontakty a odkazy ke stazeni.
  • Existuje stranka /vitezove s prehledem vitezu od roku 2002 do roku 2025.
  • Je doplnen vitez roku 2025: E-FYZIO MILETIN.
  • Hero obsahuje akce Prihlasit muzstvo a Zobrazit propozice.
  • SEO metadata jsou nastavena pro hlavni stranku, registraci, propozice a viteze.
  • Build projektu aktualne prochazi prikazem npm run build.
